# COVID-19 CT Segmentation
 
Pipeline de extracción, limpieza, análisis exploratorio (EDA) y transformación de datos
para el problema de segmentación de la competencia de Kaggle
[COVID Segmentation](https://www.kaggle.com/competitions/covid-segmentation).
 
El objetivo del dataset es, a partir de cortes de tomografía computarizada (CT) de
pulmón, segmentar tres tipos de hallazgo por píxel: **vidrio esmerilado**,
**consolidación** y **otros tejidos pulmonares afectados**, además de un canal de
**fondo**.
 
## Contenido del repositorio
 
| Archivo | Descripción |
|---|---|
| `etl_eda.ipynb` | Carga de datos, limpieza, análisis exploratorio y transformación final a arreglos listos para entrenamiento. |
 
Por ahora este es el único artefacto del repo.
